# Нефункциональные требования и стек

## Нефункциональные требования

| ID    | Категория          | Требование                                                                      |
|-------|--------------------|---------------------------------------------------------------------------------|
| NFR-1 | Безопасность       | Пароли хранятся только как хэш PBKDF2-SHA256 с солью (200 000 итераций)          |
| NFR-2 | Безопасность       | Токен доступа подписан HMAC и имеет срок жизни, подпись сравнивается безопасно   |
| NFR-3 | Безопасность       | Права проверяются в сервисе при каждом действии, а не только в интерфейсе        |
| NFR-4 | Безопасность       | Публичная регистрация создаёт только роль `student`                              |
| NFR-5 | Безопасность       | SQL-запросы параметризованы, формы защищены CSRF-токеном                         |
| NFR-6 | Производительность | Операции с профилем и оценками выполняются быстрее 200 мс при 10 000 пользователей |
| NFR-7 | Переносимость      | Python 3.9+, ядро модуля использует только стандартную библиотеку                |
| NFR-8 | Качество кода      | Покрытие тестами не ниже 80 %, код проходит flake8, black, isort                 |
| NFR-9 | Расширяемость      | Роли и права меняются в одной таблице `ROLE_PERMISSIONS`                         |

## Ограничения

- Хранилище SQLite, рассчитано на учебный масштаб.
- Нет сброса пароля, подтверждения email и отзыва токена.
- Нет ограничения числа попыток входа.
