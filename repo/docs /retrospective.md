# Ретроспектива проекта

## 1. Что получилось хорошо

1. **Разработка функционального модуля.** Удалось реализовать личный кабинет студента с тремя ролями: студент, преподаватель и администратор. Для каждой роли предусмотрены собственные права доступа.

2. **Автоматизация проверки качества.** Настроен GitHub Actions, подготовлены автоматические тесты. В результате последнего успешного запуска пройдены все 33 теста, покрытие кода составило 82%.

3. **Организация командной разработки.** Созданы рабочая ветка, Pull Request, проведён Code Review с двумя замечаниями, выполнены исправления и получено одобрение второго участника. Изменения успешно объединены с main.

## 2. Что можно улучшить

1. **Покрытие кода тестами.** Текущее покрытие составляет 82%. Некоторые участки программы остаются непроверенными, поэтому необходимо расширить набор автоматических тестов.

2. **Организация процесса разработки.** В процессе настройки GitHub возникали трудности с созданием различий между ветками и организацией одобрения Pull Request. В дальнейшем необходимо заранее планировать изменения и распределение обязанностей между участниками.

## 3. Одно действие для улучшения

В следующем этапе разработки необходимо увеличить покрытие кода автоматическими тестами, уделив особое внимание непроверенным участкам приложения и обработке ошибок.

## 4. Итог

В ходе учебной практики был разработан и проверен модуль личного кабинета студента. Настроены GitHub Actions, автоматическое тестирование, Code Review и управление версиями. Подготовлена и опубликована первая версия проекта v0.1.0.
