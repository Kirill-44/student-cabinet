## [0.1.0] - ДАТА_РЕЛИЗА
### Добавлено
- Модуль `student_cabinet`: регистрация, вход по подписанному токену, профиль, оценки, роли `student` / `teacher` / `admin`
- Хранение паролей в виде PBKDF2-хэша, параметризованные SQL-запросы
- Демо-сайт на Flask и Jinja2: кабинет студента, страницы преподавателя и администратора, защита форм от CSRF
- Метод `list_students()` для списка студентов
- 33 unit-теста, покрытие 82 %
- CI на GitHub Actions: сборка, flake8, black, isort, pytest с покрытием
- Пост-мердж проверка (smoke-тест) после слияния в `main`
- Pre-commit хуки, шаблоны Pull Request и Issue

### Исправлено
- Нет, это первый релиз.

### Известные ограничения
- Нет сброса пароля и подтверждения email
- Нет ограничения числа попыток входа
- Токен нельзя отозвать до окончания срока действия
- BUG-1 (Issue «Студент видит форму выставления оценки»): студент видит форму выставления оценки на странице `/students/<свой id>` (отправка запрещена, 403)
